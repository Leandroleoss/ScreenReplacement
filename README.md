# ScreenReplacement

# 🖥️ Configurador Visual de Telas e Monitores (AutoHotkey v2)

Um script prático e automatizado em **AutoHotkey v2** com interface gráfica (GUI) que permite configurar e posicionar automaticamente múltiplos aplicativos, URLs e navegadores (**Chrome**, **Firefox**, **Brave**, **Edge** e **Executáveis**) em telas ou monitores específicos da sua máquina.

## 🚀 Funcionalidades

- **Detecção Automática de Monitores:** Identifica automaticamente a quantidade e a área útil (descontando a barra de tarefas) de todos os monitores conectados.
- **Suporte Multi-Navegador:** Abertura inteligente em novas janelas com suporte a Chrome, Firefox, Brave e Microsoft Edge.
- **Posicionamento Personalizado:** Ajuste dinâmico das janelas para:
  - Tela Cheia
  - Metade Esquerda
  - Metade Direita
  - Parte Superior
  - Parte Inferior
- **Persistência de Dados:** Salva automaticamente suas preferências em um arquivo de configuração local (`configuracoes.ini`).

## 📋 Pré-requisitos

Para executar este script, você precisa ter instalado no seu computador:

- **Windows 10 ou 11**
- **AutoHotkey v2.0+** (Download oficial em [autohotkey.com](https://www.autohotkey.com/))
